# 十条演示的轨迹与标注修订

本轮验收对象是 Isaac Sim 的真实顺序 RGB-D、运动学教师控制及配套路线语言。旧版保留为拒收对照，不混入最终十条数据。

| 阶段 | 实际问题 | 修改与验收 |
|---|---|---|
| V11 分段教师 | 路径折点反复原地转向，视角抖动 | 保留原始序列供对比，停止继续收集 |
| V12 全局平滑 | 全局曲线产生额外绕行，终点还要原地朝向目标 | 改为全局可见路径简化和局部转弯曲线，行进中完成目标朝向 |
| V13 行进到达 | 用户要求留足墙距，首条局部车身墙距不足一米 | 在贴近处平滑向洞内修正最多 0.15 米；完整路线以 1.05 米扩张车体检查，不改洞壁和障碍 |
| V13 实际几何执行 | 寻路栅格额外离散膨胀误拒已通过实际几何的姿态 | 执行阶段显式使用 `actual_geometry`，保留原障碍、轮支撑、车腹、空气包络及扫掠检查 |
| V13 配套路线语言 | 固定任务过短，不能与“分叉左转、经过月球车”的说明对应 | 根据实际顺序生成固定路线提示，三个 query 保持相同目标和地标顺序，关键帧说明与同帧观测/控制核对 |
| V13 分叉证据 | 旧辅助中心线门槛漏掉宽通道另一侧的真实视角 | 按实际通道归属核对方向，保持当前深度、双开口和中间岩石门槛；旧 raw 不改，只生成有来源记录的派生视图 |
| V13 query 校验 | 旧规则误拒语义正确的“目标是月球车”，只认可“找到/寻找” | 窄修显式目标陈述的识别，错误目标及虚构分叉仍拒收；保留旧拒绝记录，从原主模型缓存恢复已付响应，修复未新增 API 请求 |
